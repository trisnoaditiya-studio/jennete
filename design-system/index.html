Color

Dua lapis token. Primitive menyimpan nilai mentah, semantic menyimpan makna (bg, text, border, brand, status). Komponen hanya memakai token semantic. Klik swatch untuk menyalin nama variabelnya.

Gradien & scrim

Aturan pemakaian

Ungu = aksi

Brand #5D447D dipakai untuk CTA utama, state terpilih, ikon, dan link "lihat semua". Jangan dipakai untuk blok teks panjang atau latar section penuh.

Ink = struktur

Hampir semua UI dibangun dari ink + putih. Section gelap (bg-inverse) dipakai untuk memberi ritme: trust strip, cara sewa, komparasi, footer.

Hijau = WhatsApp

Hijau #1A7F45 khusus untuk kanal WhatsApp dan indikator "live". Status sukses di form memakai token yang sama.

Aksesibilitas

Rasio kontras dihitung otomatis di browser dari token (WCAG 2.x). Target AA: 4.5:1 untuk teks normal, 3:1 untuk teks besar (≥ 24px, atau ≥ 18.66px bold).

green.600 diganti dari #1F8F4E (4.12:1) ke #1A7F45 (sekitar 5.0:1). Teks putih 16px sekarang lolos AA, dan hover #18763F tetap lebih gelap.

Teks placeholder foto

ink.500 #8A9197 di atas putih hanya sekitar 3.2:1. Pakai hanya untuk ikon dekoratif, jangan untuk teks yang harus dibaca.

Checklist

  • Fokus selalu terlihat: :focus-visible berupa outline 2px currentColor atau ring ungu 3px pada input.
  • Touch target minimal 44px (--size-control-sm), default 48px.
  • Slider hero bisa di-pause, dan autoplay mati saat prefers-reduced-motion.
  • Ikon dekoratif memakai aria-hidden, tombol yang hanya berisi ikon wajib punya aria-label.
  • Error form memakai aria-invalid="true" + aria-describedby ke .fm-err.

Cara pakai

Struktur file

design-system/
├── tokens/
│   ├── design-tokens.json   ← single source of truth
│   ├── tokens.css           ← generated
│   └── tokens.js            ← generated (dipakai styleguide)
├── build-tokens.py
├── components.css
├── assets/
└── index.html               ← styleguide ini

Alur kerja

  1. Ubah nilai di design-tokens.json.
  2. Jalankan python3 design-system/build-tokens.py.
  3. Di halaman, muat tokens.css lalu components.css.
  4. Nama class mengikuti situs (.btn-dark, .vcard, .how, dst.). tokens.css juga menyediakan alias lama (--ink, --brand, --r …), jadi CSS situs yang sekarang tetap jalan.
  5. Komponen baru: pakai token semantic --color-*, jangan hex mentah.
